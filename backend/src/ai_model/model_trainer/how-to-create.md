STEPS TO RUN THE TRAINER AND CREATE THE MODEL

STEP 1:
OPEN THE GOOGLE COLLAB IN CHROME

STEP 2:
UPLOAD THE "SmartSakayAI_Trainer.ipynb"

STEP 3:
NAVIGATE TO GOOGLE COLLAB FILES AND UPLOAD THE TRAINER DATASET "smartsakay_dataset_v3_train.jsonl" AND THE VALIDATION DATASET "smartsakay_dataset_v3_val.jsonl"

STEP 4:
CLICK RUN ALL AND WAIT FOR ALL THE CODE TO RUN AND WAIT FOR THE GGUF FILE TO INSTALL

STEP 5:
IF THE DOWNLOAD DIDN'T PUSH THROUGH, GO TO YOUR GOOGLE DRIVE, FIND THE SMARTSAKAY FOLDER, AND DOWNLOAD THE GGUF FILE THERE.

STEP 6:
MOVE THE GGUF FILE FROM DOWNLOADS TO THE "trained_model" FOLDER IN THE SMARTSAKAY SYSTEM FOLDER

STEP 7:
NEXT, INSTALL OLLAMA IN A WEB BROWSER

STEP 8:
OPEN A TERMINAL IN THE SMARTSAKAY SYSTEM AND DO:
"cd backend/src/ai_model/model_trainer/trained_model"

STEP 9:
IN THE SAME TERMINAL, ENTER:
"ollama create smartsakay_ai -f Modelfile"

STEP 10:
AFTER CREATION, TEST THE MODEL BY ENTERING:
"ollama run smartsakay_ai"

OR

"ollama list"
TO TEST THE AI OR VIEW THE MODEL.
